MW3 SP Mods - 한글패치 + 패드 모드 호환 & 패드 진동
(세 모드가 서로 충돌하지 않도록 포팅했습니다)
=====================================================

[설치 - 3단계]  게임 폴더 = iw5sp.exe 가 있는 곳
1. 한글패치     https://blog.naver.com/gamemixblog/222982734386
2. 패드 모드    https://github.com/TheTronuo/MW3GamepadFix/releases/download/v0.8.9/MW3GamepadFix-0.8.9-ASI.zip
                -> 압축 풀어 게임 폴더에 복사
3. 이 압축파일의 파일 전부를 게임 폴더에 복사 (winmm.dll 덮어쓰기 = 예)

[진동 설정]  MW3Rumble.ini 수정 후 게임 재시작. Strength=0 이면 진동 끔.
[제거]       MW3KoreanBridge.asi, MW3Rumble.asi, MW3Rumble.ini 삭제.
[주의]       싱글플레이 전용. Activision과 무관한 비공식 팬 모드.

[Install - English]
1. (optional) Korean patch   2. MW3GamepadFix 0.8.9 (link above)
3. Copy every file in this zip next to iw5sp.exe (overwrite winmm.dll = yes)
