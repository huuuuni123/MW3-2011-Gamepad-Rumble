MW3 SP Mods - 한글패치 호환 브리지 + 패드 진동
=================================================

[설치]
1. MW3 한글패치와 MW3GamepadFix(https://github.com/TheTronuo/MW3GamepadFix)를 먼저 설치하세요.
2. 이 압축파일 안의 파일을 전부 게임 폴더(iw5sp.exe가 있는 곳)에 복사하세요.
   winmm.dll 덮어쓰기를 물으면 "덮어쓰기" 해도 됩니다 (같은 Ultimate ASI Loader).
3. 게임 실행.

[진동 설정]
MW3Rumble.ini 수정 후 게임 재시작. Strength=0 이면 진동 끔.

[제거]
MW3KoreanBridge.asi, MW3Rumble.asi, MW3Rumble.ini 삭제.

[주의]
싱글플레이 전용입니다. 멀티플레이에서는 사용하지 마세요.
Activision과 무관한 비공식 팬 모드입니다.
